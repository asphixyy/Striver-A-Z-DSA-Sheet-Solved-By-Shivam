# Jumping Numbers

## Problem Statement
Given a positive number `X`. Find all jumping numbers smaller than or equal to `X`. A number is called a jumping number if all adjacent digits in it differ by exactly 1. All single-digit numbers are considered as Jumping Numbers.

## Input Format
Single line of input containing the value of `X`.

## Output Format
Jumping Numbers in a single line in sorted order (smaller to larger).

## Constraints
`1 <= X <= 5000`

```text
50
