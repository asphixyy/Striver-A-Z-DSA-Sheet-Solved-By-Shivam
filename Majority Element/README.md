# Majority Element

## Problem Statement

Given an array (arr) having N integers, find the majority element. The majority element is the element that appears more than floor(n/2) times. If there is no majority element, print **No Majority Element**, without quotes.

You may assume that the array is non-empty.

## Input Format

Two lines of input:
- The first line contains the value of N.
- The next line contains array elements in space-separated format.

## Output Format

An integer or **No Majority Element** (without quotes), as the case may be.

## Constraints

- 1 <= N <= 100
- -10^3 <= arr[i] <= 10^3

## Sample Input

```
7
2 2 1 1 1 2 2
```

## Sample Output

```
2
```
