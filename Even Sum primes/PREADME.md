# Even Sum Primes

## Problem Statement
Count the prime numbers in a given range having an even digit sum. The range is defined by its first value (`A`) and the last value (`B`), both inclusive.

## Input Format
Two lines of input. The first line contains `A` and the second line contains `B`.

## Output Format
An integer.

## Constraints
`1 <= A, B <= 100`

```text
10
25
